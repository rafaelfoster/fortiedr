Documentation Checklist

Overview API Reference Checklist
  • Installation instructions in docs/index.md and README.md match current Python/dependency versions.
  • Authentication flow documented (constructor args, auth probe behavior, TLS toggle, enable_debug).
  • Response structure and error handling noted ({"status": bool, "data": ...} with status_code/error_message on failures).
  • File transfer behavior covered (download writes timestamped files; upload expects requests-style mapping).
  • Primary wrappers documented in docs/api_reference.md (Administrator, ApplicationControl, Audit, AvScannerFileController, CommunicationControl, Events, Exclusions, Features, ForensicAnalysis, Forensics, HashSearch, Incidents, IntegrationsSupport, Integrations, Inventory, IoT, IPSets, Mobile, Organizations, PlaybooksPolicies, Policies, ThreatHunting, Users).
  • Additional/experimental wrappers documented with usage guidance (Admin, CollectorInventory, Dashboard, MobileInventory, Notifications, Reputation, SecureBrowser, SecureBrowserService, SendableEntities, Support, SystemComponents, SystemEvents, ThreatHuntingExclusions, ThreatHuntingSettings, WorkloadGroups, WorkloadsDeployment).
  • Quickstart example in docs/index.md and example.py use consistent constructor args and attribute names.
  • README.md links to the docs folder for GitHub Pages/PyPI long description.
  • Any new endpoints added after this version are appended to docs/api_reference.md and revalidated against this list.
