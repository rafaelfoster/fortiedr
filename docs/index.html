FortiEDR Python Client

Overview API Reference Checklist PyPI

An open-source Python library that wraps the FortiEDR REST API. The client handles authentication, basic HTTP plumbing, and groups endpoints into small Python classes so you can script FortiEDR administration, inventory, threat hunting, and integrations.

Python 3.8+ requests SSL verify on by default

Installation

pip install fortiedr

Or install from source:

git clone https://github.com/rafaelfoster/fortiedr.git
cd fortiedr
pip3 install .

Authenticating

Create a FortiEDR REST API user in the Management console and ensure the user logs in once to change the initial password.

from fortiedr import FortiEDR

fedr = FortiEDR(
    host="your-management-host.example.com",  # hostname only, no https://
    user="api-user",
    password="SuperSecret!",
    organization="ORG_NAME",                  # optional, case sensitive
    enable_debug=False,                       # set True to log request details
    enable_ssl=True                           # set False to skip TLS verification
)

if not fedr.auth["status"]:
    raise SystemExit(f"Authentication failed: {fedr.auth['data']}")

The client builds a Basic Auth header, validates it against the FortiEDR gateway, and stores it in fedr.headers for subsequent calls.

Responses & errors

Every helper returns {"status": True|False, "data": <response json|text|error dict>}.

  • status=True → HTTP 2xx and JSON (or text) parsed successfully.
  • status=False → data.status_code and data.error_message include server reply or Python exception text.

HTTP helpers on the client

  • get(url, params=None, request_type=None)
  • send(url, params=None, request_type=None) — POST
  • insert(url, params=None, request_type=None) — PUT
  • update(url, params=None, request_type=None) — PATCH
  • delete(url, params=None, request_type=None)
  • download(url, params=None, request_type=None, file_format="zip", download_folder="") writes to disk and returns the path.
  • upload(url, file, params=None, request_type=None) sends multipart form data.
  • enable_debug() prints URLs, headers, and payloads and enables requests debug logging.

Use these for endpoints that do not yet have a convenience wrapper.

Wrappers & surface

FortiEDR wires the primary wrappers as attributes: administrator, application_control, audit, av_scanner_file_controller, communication_control, events, exclusions, features, forensic_analysis, forensics, hash_search, incidents, integrations_support, integrations, inventory, iot, ip_sets, mobile, organizations, playbooks_policies, policies, threat_hunting, users.

Full per-method coverage lives in the API Reference. Additional experimental wrappers are also documented there.

Example usage

from fortiedr import FortiEDR

fedr = FortiEDR(host="...", user="...", password="...")
events = fedr.events.list_events()

if events["status"]:
    print(events["data"])
else:
    print(events["data"]["error_message"])

See example.py in the repository for a longer walkthrough (cloning policies, listing collectors, fetching incidents, etc.).

Troubleshooting

  • Set enable_debug=True when constructing the client or call enable_debug() later to log requests.
  • Keep enable_ssl=True unless you explicitly want to skip TLS verification (lab use only).
  • Authentication issues show as {"status": False, "data": "Unauthorized" | "Forbidden" | ...} from the auth probe.
