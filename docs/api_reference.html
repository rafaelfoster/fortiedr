FortiEDR API Reference

Overview API Reference Checklist

This reference lists every public class and function in the repository. Names mirror the FortiEDR REST endpoints they wrap.

Core client

FortiEDR

  • FortiEDR(host, user, password, organization=None, enable_debug=False, enable_ssl=True) builds Basic Auth headers, probes the management host, and wires wrappers.
  • enable_debug() turns on verbose requests logging and prints URL/headers/payload.
  • get, send (POST), insert (PUT), update (PATCH), delete, download (saves to disk, returns path), upload (multipart).
  • Every helper returns {"status": bool, "data": response|error}; on failure data holds status_code and error_message.

Auth

  • convert_to_base64(string): encodes credentials.
  • test_authentication(headers, host): probes two URLs to validate credentials; returns status, data, response headers.
  • get_headers(fedr_host, fedr_user, fedr_pass, fedr_org=None): builds the Basic Auth header and returns it with host, or (None, error) on failure.

Primary wrappers (attached to FortiEDR)

All methods return the standard {"status": bool, "data": ...} envelope. Below are full signatures with argument types and descriptive behavior (all support an optional organization parameter unless noted).

Administrator

  • list_system_summary(organization: str|None=None) — Retrieves management hostname, version, external/internal IPs, and license expiration for the specified organization or default tenant.
  • upload_license(licenseBlob: bytes) — Uploads a FortiEDR license file; pass the raw bytes or a file-like object in a {"licenseBlob": ...} mapping.
  • list_users(organization: str|None=None) — Returns the roster of FortiEDR management users.
  • get_user(username: str, organization: str|None=None) — Fetches a single user record by username.
  • delete_user(username: str, organization: str|None=None) — Removes a user account from the management console.
  • create_user(firstName: str, lastName: str, password: str, confirmPassword: str, email: str, username: str, title: str, role: str, restApi: bool, customScript: bool, remoteShell: bool, organization: str|None=None) — Creates a user with the given role and capability flags (REST API, custom scripts, remote shell).
  • update_user(username: str, firstName: str|None=None, lastName: str|None=None, password: str|None=None, confirmPassword: str|None=None, email: str|None=None, title: str|None=None, role: str|None=None, restApi: bool|None=None, customScript: bool|None=None, remoteShell: bool|None=None, organization: str|None=None) — Updates identity fields, password, role, and capability flags for an existing user.

ApplicationControl

  • add_app_to_app_group(application: str, applicationGroup: str, organization: str|None=None) — Places an application into a named application group.
  • add_app_group(applicationGroup: str, organization: str|None=None) — Creates a new application group for policy targeting.
  • delete_app_from_app_group(application: str, applicationGroup: str, organization: str|None=None) — Removes an application from the specified group.
  • delete_app_group(applicationGroup: str, organization: str|None=None) — Deletes an application group and its membership.
  • list_app_groups(organization: str|None=None) — Lists all application groups available to the tenant.
  • list_apps_in_app_group(applicationGroup: str, organization: str|None=None) — Lists applications that belong to a given group.
  • list_collectors_for_app(application: str, organization: str|None=None) — Shows collectors where a particular app is installed.
  • list_installed_apps(collectorId: str, organization: str|None=None) — Returns installed applications on a specific collector.

Audit

  • get_system_audit(startDate: str, endDate: str, organization: str|None=None) — Pulls audit log entries between two timestamps (string format accepted by the FortiEDR API).

AvScannerFileController

  • upload_file(file: bytes, organization: str|None=None) — Sends a file to the AV scanner; pass a {"file": open(...,"rb")}-style mapping.

CommunicationControl

  • add_exception(ruleName: str, organization: str|None=None) — Creates a communication-control exception rule by name.
  • delete_exception(ruleName: str, organization: str|None=None) — Deletes a specific communication-control exception rule.
  • list_exceptions(organization: str|None=None) — Lists all communication-control exception rules.

Events

  • acknowledge_event(eventId: int, organization: str|None=None) — Marks the event as acknowledged in FortiEDR.
  • add_comment_to_event(eventId: int, comment: str, organization: str|None=None) — Adds a textual comment to an event record.
  • get_event(eventId: int, organization: str|None=None) — Retrieves full details for a single event.
  • get_event_process_info(eventId: int, organization: str|None=None) — Returns process lineage/details associated with the event.
  • list_event_comments(eventId: int, organization: str|None=None) — Lists comments posted to the event.
  • list_events(organization: str|None=None) — Lists events for the tenant with default FortiEDR paging.
  • unacknowledge_event(eventId: int, organization: str|None=None) — Reverts an event to an unacknowledged state.

Exclusions

  • add_exclusion(ruleName: str, organization: str|None=None) — Creates an exclusion rule by name.
  • delete_exclusion(ruleName: str, organization: str|None=None) — Removes an exclusion rule.
  • list_exclusions(organization: str|None=None) — Returns the current set of exclusion rules.

Features

  • get_feature_parameters(featureName: str, organization: str|None=None) — Fetches configurable parameters for a named feature (e.g., threat_hunting).

ForensicAnalysis

  • get_file_from_collector(collectorId: str, filePath: str, organization: str|None=None) — Requests and downloads a specific file from a collector.
  • get_process_info_from_collector(collectorId: str, processId: int, organization: str|None=None) — Retrieves process details directly from the collector host.
  • list_running_processes_from_collector(collectorId: str, organization: str|None=None) — Lists currently running processes on a collector.
  • abort_request(collectorId: str, requestId: str, organization: str|None=None) — Cancels a previously issued forensic request.
  • get_file_from_collector_ext(collectorId: str, filePath: str, organization: str|None=None) — Extended API variant for file retrieval.
  • get_process_info_from_collector_ext(collectorId: str, processId: int, organization: str|None=None) — Extended API variant for process details.
  • list_running_processes_from_collector_ext(collectorId: str, organization: str|None=None) — Extended API variant for listing processes.

Forensics

  • get_file(collectorId: str, filePath: str, organization: str|None=None) — Downloads a file using the forensics endpoint (management-mediated).
  • get_process_details(collectorId: str, processId: int, organization: str|None=None) — Retrieves process details via forensics.
  • list_processes(collectorId: str, organization: str|None=None) — Lists processes for a collector through the forensics API.

HashSearch

  • search(hash: str, organization: str|None=None) — Searches FortiEDR for evidence of the provided file hash.

Incidents

  • add_comment_to_incident(incidentId: int, comment: str, organization: str|None=None) — Adds an analyst comment to an incident.
  • get_incident(incidentId: int, organization: str|None=None) — Retrieves full incident details.
  • list_incidents(organization: str|None=None) — Lists incidents visible to the tenant.
  • update_incident(incidentId: int, organization: str|None=None) — Updates incident state/metadata (fields defined by FortiEDR server).
  • list_incident_comments(incidentId: int, organization: str|None=None) — Lists comments recorded on the incident.

IntegrationsSupport

  • get_ems_settings(organization: str|None=None) — Retrieves current EMS connector settings.
  • get_hoster_details(hosterType: str, organization: str|None=None) — Returns connection details for the specified hoster type.
  • get_hoster_types(organization: str|None=None) — Lists hoster types supported by the instance.

Integrations

  • add_integration(organization: str|None=None) — Creates a new integration entry (payload handled server-side).
  • delete_integration(integrationId: int, organization: str|None=None) — Removes an integration by ID.
  • get_integration(integrationId: int, organization: str|None=None) — Retrieves details for a specific integration.
  • list_integrations(organization: str|None=None) — Lists all configured integrations.
  • update_integration(integrationId: int, organization: str|None=None) — Updates integration fields (payload defined by server schema).

Inventory

  • get_collector_details(collectorId: str, organization: str|None=None) — Returns hardware, OS, and status details for a collector.
  • list_collectors(organization: str|None=None) — Lists all collectors enrolled under the tenant.
  • list_groups(organization: str|None=None) — Lists collector groups.
  • move_collectors_to_group(collectorIds: int|list[int], groupId: int, organization: str|None=None) — Moves one or many collectors into the target group; single IDs are auto-wrapped into a list.
  • uninstall_collector(collectorId: str, organization: str|None=None) — Initiates a collector uninstall workflow.
  • create_group(groupName: str, organization: str|None=None) — Creates a new collector group.
  • delete_group(groupName: str, organization: str|None=None) — Deletes a collector group.
  • disable_collector(collectorId: str, organization: str|None=None) — Disables a collector.
  • enable_collector(collectorId: str, organization: str|None=None) — Enables a collector.
  • restart_collector(collectorId: str, organization: str|None=None) — Restarts a collector service.
  • scan_collector(collectorId: str, organization: str|None=None) — Triggers an on-demand scan on the collector.
  • set_collector_policy(collectorId: str, policyName: str, organization: str|None=None) — Assigns a specific policy to a collector.
  • assign_policy_to_group(groupId: int, policyName: str, organization: str|None=None) — Assigns a policy to an entire collector group.
  • get_collectors_by_group(groupName: str, organization: str|None=None) — Lists collectors belonging to a named group.
  • get_group_policy(groupName: str, organization: str|None=None) — Retrieves the policy currently applied to a group.

IoT

  • create_iot_group(groupName: str, organization: str|None=None) — Creates an IoT device group for segmentation.
  • delete_iot_group(groupName: str, organization: str|None=None) — Deletes an IoT group by name.
  • list_iot_devices(organization: str|None=None) — Lists IoT devices discovered or managed.
  • list_iot_groups(organization: str|None=None) — Lists defined IoT groups.
  • move_iot_devices_to_group(deviceIds: int|list[int], groupId: int, organization: str|None=None) — Moves one or more devices into a group (single IDs auto-wrapped to list).

IPSets

  • add_ip_set(name: str, description: str, ips: str|list[str], organization: str|None=None) — Creates an IP set with description and members (accepts single IP string or list).
  • delete_ip_set(name: str, organization: str|None=None) — Deletes a named IP set.
  • list_ip_sets(organization: str|None=None) — Lists configured IP sets.
  • update_ip_set(name: str, new_name: str|None=None, description: str|None=None, ips: str|list[str]|None=None, organization: str|None=None) — Renames, re-describes, or replaces members in an IP set.

Mobile

  • list_incidents(organization: str|None=None) — Lists mobile incidents.

Policies

Users

  • create_user(firstName: str, lastName: str, password: str, confirmPassword: str, email: str, username: str, title: str, role: str, restApi: bool, customScript: bool, remoteShell: bool, organization: str|None=None) — Creates a user (same fields as Administrator).

  • get_user(username: str, organization: str|None=None) — Retrieves a user record.

Additional/experimental wrappers (manual use)

These modules are in fortiedr/api but not attached to FortiEDR. Some rely on HTTP helpers like post or put that you can alias:

from fortiedr import FortiEDR
from fortiedr.api.system_components import SystemComponents

fedr = FortiEDR(...)
fedr.post = fedr.send    # POST
fedr.put = fedr.insert   # PUT
system_components = SystemComponents(fedr)
